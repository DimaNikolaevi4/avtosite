# АвтоНовости — самонаполняющийся новостной сайт

Автономный новостной сайт на PHP: собирает свежие новости из RSS, переписывает их локальной языковой моделью и публикует как статические страницы. Работает на дешёвом хостинге без cron и SSH — обновление запускается внешним планировщиком по защищённому URL либо самим посетителем по таймеру.

Часть замысла «сеть из 12 ИИ-новостных сайтов» (см. `PROJECT.md`): этот репозиторий — рабочий прототип одной площадки («АвтоНовости»).

## Как работает

1. `update.php` (или `run.php`) забирает последнюю новость из RSS-лент (Лента, ТАСС, RT, Вести, Рамблер, Фонтанка, Life, Mail.ru).
2. Текст уходит в LLM (Qwen 2.5 7B через Qubu.ai/Ollama) — модель делает рерайт на русском.
3. Результат сохраняется как статья и статическая HTML-страница; дубликаты отсекаются по хешу.
4. `index.php` показывает ленту с пагинацией, `article.php` — страницу статьи.

Обновление — раз в 180 минут (`update_interval`), это же значение использует автозапуск при заходе посетителя.

## Структура

| Файл | Роль |
|---|---|
| `index.php` | главная: лента статей, пагинация, автозапуск сборщика по таймеру |
| `article.php` | страница статьи (`?h=…`) |
| `update.php` | сборщик: cron или браузер по ключу |
| `run.php` | полная версия сборщика (тоже под ключом) |
| `functions.php` | ядро: RSS, запрос к LLM, дедупликация, сохранение, кэш, логи |
| `visitor.php` | счётчик посетителей (`data/visitors.json`) |
| `sitemap.php`, `robots.php` | SEO: карта сайта и robots |
| `config.php` | настройки; локальные переопределения — в `config.local.php` |
| `style.css`, `favicon.png` | оформление |
| `tools/debug.php`, `tools/test_fetch.php` | служебная диагностика, только из консоли |
| `PROJECT.md`, `CHECKLIST.md` | концепция сети из 12 сайтов и чек-лист работ |

Рантайм-папки `data/`, `cache/`, `news/`, `images/` создаются автоматически и в репозиторий не попадают.

## Настройка

1. Скопируйте `config.php` в `config.local.php` и задайте там то, что не должно попадать в git:

```php
<?php
return [
    'update_key'    => 'длинный-случайный-ключ',
    'allow_web_run' => true,   // если сборщик запускается из браузера/планировщика
];
```

2. `config.local.php` в `.gitignore` и закрыт в `.htaccess`.

## Запуск

**Из консоли (рекомендуется):**

```bash
php /путь/к/update.php
```

**По cron (Beget поддерживает cron для аккаунта):**

```
0 */3 * * * /usr/bin/php /home/u/аккаунт/public_html/update.php
```

**Внешний планировщик (если cron на хостинге недоступен):** задача раз в 3 часа на URL

```
https://ваш-сайт.ru/update.php?key=ВАШ_КЛЮЧ
```

При этом в `config.local.php` должны быть `allow_web_run => true` и `update_key`.

## Безопасность

- `update.php` и `run.php` из браузера работают **только** при `allow_web_run = true` и верном ключе (сравнение через `hash_equals`); по умолчанию — только CLI.
- `data/`, `cache/`, `config.php`, `config.local.php`, `functions.php`, `visitor.php`, `tools/` закрыты в `.htaccess`.
- Служебные `tools/debug.php` и `tools/test_fetch.php` отказывают при веб-запросе (403) и вызываются только из консоли.
- Ключи и пароли храните в `config.local.php`, не в `config.php`.
